# Pong

**[▶ Play in browser](https://hangyulkimmy.github.io/pong/)**

Classic Pong, two paddles, one ball.

Made in **Unity** and exported to WebGL. This repo is the built player (`Build/`, `TemplateData/`, `index.html`) served from GitHub Pages.
